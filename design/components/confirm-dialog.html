확인 대화상자

구현 전 설계 · 원본은 M1에서 frontend/ 코드, 카탈로그는 Storybook(미정)

되돌릴 수 없는 동작은 모두 이 대화상자를 거친다. 무엇에 어떤 결과가 나는지 요약해 보이고, 기본 초점은 취소에 둔다.

동작요약에 보일 것실행 버튼
매수·매도 주문계좌, 종목, 방향·방식·시장, 가격 × 수량, 묶을 금액 또는 수량매수 빨강 / 매도 파랑
자동 주문이 꺼진 동안의 수동 주문위 주문 요약 + "자동 주문 꺼짐" 경고 줄. 실행 버튼 문구는 "꺼진 상태에서 보내기"경고
정정대상 번호, 바뀌는 가격·수량, 새 번호가 생긴다는 안내기본
취소, 미체결 주문 취소 실행번호별 취소 수량, 낸 쪽(수동·전략·강제 청산)경고
자동 주문 끄기막히는 것(강제 청산 포함)과 그대로인 것경고
자동 주문 켜기켜지는 즉시 나갈 강제 청산 목록경고
계좌 등록환경·종류·계좌번호 끝 2자리, 등록 뒤 환경을 못 바꾼다는 안내기본
리스크 한도 저장바뀌는 값의 지금 → 새 값, 느슨해짐·조여짐. 조이기만 해도 확인한다느슨해지면 경고
전략 파라미터 저장바뀌는 값, 적용 시점(다음 거래일 07:00)기본
전략 상태 전환·멈춤지금 상태 → 새 상태, 새 주문이 나가는지경고
리셋 판정 뒤 다시 켜기닫히는 포지션 계획, 새 성과 구간경고
